# Product niche

> Locked 2026-10-29 ~18:45 PDT (Android primary — Product + Lead).

## Primary
Android users who want a local-first private research / personal agent: prompts and notes stay on-device by default; no cloud-by-default; credentials never enter the model.

## Distribution
Main path: regular Android (Play Store or sideload APK). Solana Mobile / Seeker / dApp Store is not the hero channel. Web and CLI stay secondary companions.

## Promise (direction — not all shipped)
- Local-first / on-device by default; fail closed when no local model is connected.
- Notes and chat stay on the device unless the user opts into a labeled remote path (never silent; never default).
- Credentials stay out of the model.
- Crypto / on-chain optional only — never required for core use.

## Foundation (unchanged)
Privacy / fail-closed stack: local ask path, refusal gates, sanitizer-oriented design. Do not claim live source-identity masking or “local-only” as absolute if REMOTE or on-chain opt-in exists — label those paths.

## Secondary / historical
- Journalist / source-protection research framing informed early privacy work; not the current hero.
- Solana Mobile / Seed Vault positioning was a brief primary; demoted to optional crypto path.

## Out of scope for hero claims (until built + honest)
Play Store listing as live fact if not published; Seeker/dApp Store as primary; on-device phone model as a shipping product; Seed Vault; chain actions; live source-ID masking; attested remote; BYOK as default or silent fallback; unbuilt wallet/DeFi agents; silent chain calls.
