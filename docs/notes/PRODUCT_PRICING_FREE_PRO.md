# Pricing — Free / Pro (proposal)

**Status:** Lead + Product proposal for first paying professionals (2026-10-29). Not live billing. Do not invent enterprise SKUs.

## Free — local research desk

Minimum that proves the promise without a card:

- Local / on-device `ask` when a model is present; **fail closed** if missing.
- Chat-first Research desk (zinc mono).
- Heuristic secret sanitizer on boundaries (honesty: not a complete PII guarantee).
- Propose-only posture for consequential actions; credentials outside the model.
- Web companion dogfood + Android when M-A0 lands (unsigned → signed path later).
- Mode honesty labels (`LOCAL` / `DEMO · stub` / `DEMO · REMOTE` — never badge stub as protected).

**Limits (honest):** no live source-ID mask until M2; no cloud sync of vaults; community / self-serve support only.

## Pro — source-protected workflow (paid)

Minimum feature set required before charging professionals:

1. **Document / notes library** — local ingest of files and notes into a project vault on-device.
2. **Real source-identity masking (M2 ACCEPT)** — names, emails, phones, handles, code names masked before model context; mask map local and user-visible.
3. **Journalism / PI must-not-echo evals green** — CI-gated refusal on source memo / secret echo patterns (privacy rebuild, not historical crypto gate).
4. **Explicit export approval (M3)** — save / export / share only after human approve outside the model; plain-language reasons when blocked.
5. **Local model packaging** — one-tap or clear path to a verified mobile/desktop GGUF; fail closed if absent.
6. **Android primary APK / Play path** — installable professional surface (signed release), not web-only.

**Still not Pro claims:** SSO, org-wide audit suite, MDM, guaranteed anonymity, "nothing ever leaves your device" once any remote exists, provider-branded TEE marketing.

## Suggested price posture (non-binding)

- Free: forever for local desk above.
- Pro: monthly or annual seat for individuals (journalists / PIs / researchers) once items 1–6 above are ACCEPT.
- Team / newsroom: later Phase 4 — only after durable policy + project isolation; still no invented SSO until built.

Suggested band (Product): **$12–20/mo** or annual equiv. Exact dollar amounts: Lead + yoxi when Pro checklist is green.
