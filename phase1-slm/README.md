# Phase 1 — SLM Foundation

Crypto, privacy and cypherpunk domain SLM. Default model: **Qwen2.5-7B-Instruct** (see configs/model_config.yaml for the reasons). Llama-3.1-8B-Instruct is the alternative.

## Setup
Python 3.11+. A GPU is optional: QLoRA on 7B needs about 16–24GB VRAM. The 0.5B smoke model runs on CPU.
```bash
cd phase1-slm
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Commands
| Step | Command |
|---|---|
| Build dataset | `make data` / `python scripts/prepare_domain_data.py` |
| Dry-run fine-tune (tiny, CPU OK) | `make dryrun` |
| Full QLoRA | `make train` or `python scripts/finetune_qlora.py --model Qwen/Qwen2.5-7B-Instruct --data data/seed_prompts.jsonl --output outputs/qlora-adapter` |
| Smoke local inference | `make smoke` |
| Chat | `python scripts/local_inference.py [--adapter outputs/qlora-adapter]` |
| Eval | `make eval ADAPTER=outputs/qlora-adapter` (run without ADAPTER for a baseline) |

## Data
- `data/seed_prompts.jsonl` — 141 messages-format examples (97 added in Phase 1 hold) (generated by prepare_domain_data.py)
- `data/eval_prompts.jsonl` — 12 held-out prompts with rubric keywords
- To expand, drop `*.jsonl` files in the same format into `data/extra/` and re-run `make data`. Don't include real user addresses or PII.

## Privacy
Inference is fully local once the weights are cached (`HF_HUB_OFFLINE=1`). Nothing gets logged except the eval output files you choose to write.

## Security guards (Phase 1 script fixes)
- **Secret preflight:** `prepare_domain_data.py` scans SEED and every `data/extra/*.jsonl` record (all message contents + tags) via `scripts/secret_scan.py` for BIP39-like 12/24-word runs, `BEGIN … PRIVATE KEY`, ≥64-hex keys, `ed25519:` secrets, `sk-`/`api_key` shapes and long base64 blobs. Any hit prints `file:line field reason`, exits 1, and writes nothing. Never put real seeds, keys or real user addresses in data.
- **Eval safety gate:** `eval_harness.py` runs `data/eval_prompts.jsonl` (keyword score, informational only) plus `data/eval_refusal.jsonl` (R1/R2/R3 per `REFUSAL_EVAL_CRITERIA.md`). Exit 0 = all safety cases pass; exit 1 = any `must_refuse` / `must_not_echo` failure.
- **Offline inference:** `local_inference.py --offline` sets `HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1` and fails closed on cache miss; without it a warning is printed.
- **`--no-system`** is for ablations only, never user-facing; it requires `NEAR_PRIVACY_ALLOW_NO_SYSTEM=1`.
- **Seed/key scrub:** pasted seed/key input is refused locally: it is not sent to the model, not added to history, and not echoed back. Single-shot `--prompt` exits with code 2 when scrubbed.

## Without `make`
`make` may be missing on minimal boxes. Raw equivalents:
- eval-refusal: `NEAR_PRIVACY_CI=1 .venv/bin/python scripts/eval_harness.py --model Qwen/Qwen2.5-0.5B-Instruct --refusal-only --require-refusal --refusal data/eval_refusal.jsonl --out outputs/eval_refusal_results.jsonl`
- test-safety: `.venv/bin/python scripts/test_safety_unit.py`
- 7B gate: see `EVAL_REFUSAL_7B.md`
